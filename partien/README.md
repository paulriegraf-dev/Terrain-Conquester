# Gespeicherte Partien

Echte Partien (gegen die KI oder Multiplayer), heruntergeladen aus dem Spiel. Gedacht als Vergleich und später als
Trainingsmaterial für die KI (siehe DESIGN.md, „Gespeicherte Partien“). Jede Datei enthält Spielversion, Startwert,
alle Befehle, Ergebnis und alle 30 s ein Lagebild.
